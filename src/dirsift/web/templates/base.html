DirSift reads what a server volunteers. It guesses no paths, carries no credentials and writes nothing. The only thing it ever sends elsewhere is a hash you ask it to check, one file at a time.

Targets and indicators are defanged everywhere they are printed. File contents are shown raw, because the contents are the evidence.
