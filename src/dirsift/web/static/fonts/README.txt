Fonts vendored into the package so the console works with no network at all.

space-grotesk-latin.woff2   Space Grotesk, latin subset, SIL Open Font License 1.1
                            see SPACE-GROTESK-OFL.txt
jetbrains-mono-latin.woff2  JetBrains Mono, latin subset, SIL Open Font License 1.1
                            see JETBRAINS-MONO-OFL.txt

Both were taken from the Google Fonts distribution. Only the latin subset ships;
anything outside it falls back to the system stack named in dirsift.css.
